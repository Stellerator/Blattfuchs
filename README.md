# Blattfuchs 🦊

Arbeitsblätter auf dem iPad bearbeiten – für Kinder der Grundschule (Klasse 2, Inklusion):
schreiben in die Lineatur, verbinden, Silbenkönige krönen, Silbenbögen setzen, Kärtchen ziehen.

**App öffnen:** die GitHub-Pages-Adresse dieses Repositorys in Safari aufrufen →
Teilen → „Zum Home-Bildschirm“.

## Datenschutz
Alle Arbeitsblätter, Namen und Arbeitsstände bleiben **ausschließlich auf dem jeweiligen Gerät**
(Browser-Speicher). Es gibt keinen Server, keine Konten, keine Übertragung. Dieses Repository enthält
nur den Programmcode – keine Arbeitsblätter und keine Daten von Kindern.

## Dateien
- `index.html` – die komplette App (eine Datei, enthält pdf.js)
- `manifest.webmanifest`, `icons/` – für den Home-Bildschirm
- `sw.js` – Offline-Speicher (App startet auch ohne WLAN)
